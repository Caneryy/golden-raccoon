# Clawback History Evidence

## Sources

- Horizon API operations endpoint for issuer account
- Filtered for clawback, authorization, and flag operations
- Limited to 1,000 operations, 100 holders

## Limits

Max operations: 1,000. Max holders: 100. Timeout: 10s. Rate: 10/min.

## Coverage

Provider retention gaps are marked and excluded from totals. Historical data is not estimated.
